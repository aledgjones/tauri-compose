Compose UX Design Directions

Six visual directions for a calm, music-first desktop composition tool.

Each direction keeps the score as the star, uses a restrained dark-mode shell, and applies the sky-blue accent deliberately for active state and focus. The real differences are information hierarchy, visual density, panel strategy, and how much the chrome asserts itself around the score.

Dark mode only
Sky-500 accent

Meticulously organized

Evaluation lens

  • Which layout makes score work feel most direct and least ceremonial?
  • Which panel structure best supports “editing with minimal cleanup”?
  • Which direction feels most timeless and least trend-driven?
  • Which one makes it easiest to know where a tool belongs?
  • Which one feels most compatible with Dorico’s strengths without inheriting its muddle?

How to choose

Direction 1Best if you want a stable, low-risk baseline that can scale cleanly.
Direction 2Best if expert efficiency and score acreage matter most.
Direction 3Best if preventing information-architecture muddle is the top priority.
Direction 4Best if you want more visual delight without making the chrome loud.
Direction 5Best if future growth across playback and setup should follow a zoned console model.
Direction 6Best if you want maximum visual restraint and document-first calm.
Likely hybridDirections 1, 3, and 6 combine especially well for Compose’s stated goals.
Accent strategyIn all directions, sky blue is reserved for active state, focus, and critical context only.
