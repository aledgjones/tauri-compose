# Planning Artifacts

Root-level canonical files in this folder represent the active BMAD initiative.

## Active Initiative

- `prd.md`: foundational tuplet support PRD
- `architecture.md`: foundational tuplet support architecture
- `epics.md`: current epic and story breakdown for the active initiative

## Archived Initiative Context

- `archive/2026-03-multi-flow-score/`: completed multi-flow score planning set
- `archive/2026-03-tuplet-planning-history/`: readiness and planning-change history for the active tuplet initiative

## Working Rule

Keep exactly one active root-level `prd.md` and one active root-level `architecture.md`.
When an initiative is completed, move its planning set into `archive/` rather than keeping multiple current-looking PRDs at the root.
When readiness reports or sprint-change proposals stop being active planning inputs, archive them too so the root stays focused on the canonical working set.
